# RESTAURANT EMPIRE 3D — Visual Foundation

This branch is a clean rebuild, based on `main`. The earlier procedural prototype branch is not used.

## Current target
A compact, believable Belgian horeca street with a detailed ANIMO CAFE frontage, a walkable street, first-person/third-person camera, touch movement and a simple enter/exit interaction.

## Technology
- Three.js WebGL renderer
- Physically based materials, shadows and tone mapping
- CC0 textures and HDRI lighting from Poly Haven
- CC0 rigged character from Tevy
- Static web build intended for GitHub Pages and mobile Safari

## Important limitations
This is an early visual foundation, not a finished game and not yet photorealistic AAA quality. External asset hosting, texture loading, model loading and iPhone performance still need real-device verification. No paid services are used.
