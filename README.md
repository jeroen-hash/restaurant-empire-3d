# RESTAURANT EMPIRE 3D — Visual Foundation

This is a clean rebuild branch created from `main`. The earlier prototype branch and the default branch are not changed.

## Current target
A compact Belgian horeca street with a detailed ANIMO CAFE frontage, a textured road and facade, a walkable street, first-person/third-person camera, touch movement and an enter/exit interaction.

## Technology
- Three.js WebGL renderer
- Physically based materials, shadows and tone mapping
- CC0 PBR textures and HDRI lighting from Poly Haven
- Rigged and animated human model from Vinish.Dev
- Static web build intended for GitHub Pages and mobile Safari

## Important limitations
This is an early visual foundation, not a finished game and not yet photorealistic AAA quality. External asset hosting, texture loading, model loading and iPhone performance still need real-device verification. The buildings are custom-built scene geometry with PBR surface maps; they are not scanned building models. No paid services are used.
