# RESTAURANT EMPIRE 3D — Godot foundation

This folder is the beginning of the actual Godot 4 project. It is separate from the existing Three.js browser preview.

## Open the project
Open the `godot/` folder in Godot 4.x and run the main scene.

## Included in this first foundation
- Godot 4 project and main scene
- Procedurally built first street block and ANIMO CAFE shell
- CharacterBody3D player with third-person camera
- Keyboard movement and initial touchscreen drag controls
- Central game state and versioned local JSON save/load

## Not implemented yet
This is a technical starting point, not a finished game. It does not yet contain character animation, detailed production-quality art, customer/staff AI, kitchen workflow, stock/economy gameplay, school/career progression, vehicles, multiplayer, or a mobile UI joystick. Those systems will be added as separate modules and tested in Godot.

## Validation
The repository's GitHub checks validate the web preview. They do not run the Godot engine. The Godot project must still be opened and tested in Godot 4 before it can be called engine-tested.
