# First editor session — RESTAURANT EMPIRE 3D

This checklist is intentionally short. Do not create a new project from the Unreal launcher: open the existing `RestaurantEmpire.uproject` in this repository branch.

## Before opening

- Finish installing the chosen Unreal Engine 5 version in Epic Games Launcher.
- Confirm the installed version number in the Launcher Library.
- Extract/download the repository branch `unreal5/vertical-slice` if it is not already on the PC.
- The project file is `unreal5/RestaurantEmpire.uproject`.

## First launch

1. Open `RestaurantEmpire.uproject`.
2. If Unreal asks which engine version to use, select the installed UE5 version.
3. If asked to rebuild missing modules, choose **Yes** / **Build**.
4. Wait for shader compilation and initial project loading to finish.
5. If compilation fails, stop and capture the exact first error; do not repeatedly change settings.
6. Confirm the editor opens. This is the first technical checkpoint; no playable kitchen is claimed yet.
